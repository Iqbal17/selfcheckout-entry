One funny remark in the voice of a smug, judgmental self-checkout machine — the sort of line the till would say to a shopper buying twelve yoghurts and nothing else. The program writes the chosen line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).

## Run it

```sh
python3 main.py
```
